# A股脉冲

一个适合 GitHub Pages 的纯静态行情面板。页面加载后由浏览器直接请求东方财富公开行情接口，不内置、不回退到演示行情。

## 发布到 GitHub Pages

把本目录中的全部文件放到仓库根目录或 `docs/` 目录，Pages 构建方式选择 **Deploy from a branch**，即可直接发布。项目使用相对路径，放在 `https://用户名.github.io/仓库名/` 下也能正常加载。

## 本地预览

需要通过 HTTP 服务打开，不能直接双击 `index.html`，因为浏览器会限制跨域请求。任意静态服务器均可，例如：

```bash
python -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

## 数据与限制

- 指数、行业、个股快照和日K线均来自东方财富公开接口，由浏览器端实时请求。
- 如果网络、浏览器策略或东方财富接口不可达，页面会保留为空状态并提示失败，不会伪造数字。
- “我的关注”只保存在当前浏览器的 `localStorage` 中，不上传任何数据。
- 行情仅供研究，不构成投资建议。
