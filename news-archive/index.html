口径说明

本页把每个快照交易日的「财联社新闻筛选篮子」留档成一张表： 篮子内每一只股票都保留当日的分桶（可执行 / 观察 / 回避）、博弈档位、可执行分、盈亏比、低吸位、止损位、潜力分、是否收盘封板， 以及看板快照自带的 T+1 ~ T+5 后续涨跌。
  • 覆盖口径：看板 news.json 快照中出现的全部股票（剔除仅由「龙虎榜」相关栏目命中的个股，栏目名含「龙虎榜」即视为龙虎榜系）。四桶（可执行 / 观察 / 回避 / 复盘池）沿用「可交易清单」的 aggregate / classify 口径；未落入四桶的股票以「纳入」桶全量归档，不按分数漏股。
  • 深度因子（按《深度研报分析流程》采集）：① 主力资金流向（当日 + 近 20 日，东财主源 / 新浪备用）；② 机构评级与一致目标价（近 90 天研报：评级、机构家数、买入+增持占比、目标价均值与隐含空间）；③ 商誉与负债率（最新报告期）；④ 估值快照（PE/PB/总市值/量比，腾讯批量行情）；⑤ 技术面衍生（RSI14、距 60 日高点回撤、20 日波动率、MA20 斜率、量能比，60 日日K 计算）；⑥ 业绩因子（营收/归母/扣非同比、毛利率、ROE，含归母 vs 扣非背离校验）；⑦ 限售解禁（未来最近一次日期/市值/占比）；⑧ 业绩验证日历（未来最近一次预约披露日 + 最新业绩预告类型与净利区间，东财数据中心）。由云端 deep-factors.js 采集并随快照存档；未取得时显示「—」，不影响其余结论。
  • 交叉验证裁决：分析弹窗在综合结论下方给出「技术面 × 基本面 × 资金面」三维校验——目标价验证（现价超一致目标价 → 不追高）、逻辑冲突降级（技术面强但亏损/PE 极高 → 事件博弈降档）、非经常损益校验（表观增速与扣非背离 → 以扣非定性）、风险一票否决（商誉占比 ≥30%、亏损纯题材、PE>150）、解禁日历（90 日内大额解禁提示减仓窗口）、位置提示（贴近 60 日新高追高谨慎）、追高警示（20 日涨幅透支且跑在扣非增速前面 → 情绪外溢勿追，短期/中期档位封顶「谨慎可操作」）、破位勿接飞刀（下降趋势 / 20 日跌 15%+ → 等缩量企稳+站回 MA20 右侧确认）、财报验证日历（45 日内预约披露日作为逻辑证伪/证实节点，披露前仓位保守）。
  • 发布时间：表格「发布时间」列为该股在财联社看板中最新一条相关新闻的发布时间（取自快照 time 字段）；顶部日期筛选仍按快照日分组。点击股票名称可在腾讯自选股（gu.qq.com）打开个股页。
  • 档位 / 分桶 / 评分逻辑：① 档位取看板多条新闻中更强的博弈档位（适合 > 可关注 > 中性 > 不适合 > 样本不足），价位随档位同步；② 可执行 = 可交易 + 未封板且未接近涨停（按 10/20/5cm 板块限制各自判断，替代原硬编码 9.5%）+ 站上 20 日线 + 非下降趋势 + 风险标签 < 2 + 无减持/立案 + 盈亏比 ≥1.5 + 现价不低于低吸位；③ 回避修正：原逻辑要求可执行分 < 20 才回避，导致「不适合」档位、减持/立案、双风险标签但催化较多的股票滑入观察——现改为上述明确负面信号直接回避（下降趋势仍保留分数门槛）；④ 量能惩罚修正：原「量比 ≥ 前日 100% 即扣分」会惩罚正常温和放量，改为 ≥250% 扣 3 分、≥400% 扣 5 分（与其 Stockbee 统计「放量越极端短期回撤越大」一致）；⑤ 潜力分沿用看板模型分（0–100）线性映射；⑥ 盈亏比目标价统一按现价 +8% 估算（口径一致的保守假设）。
  • 归档节奏：每轮快照（盘中约 10 分钟）追加到当日，按日去重，最多保留最近 45 个快照日。
  • T+n 口径：取自快照自带的 forward 字段，随快照滚动补齐；超出保留窗口的旧记录停在最后一次见到的值。
  • 不构成投资建议：价位为位置参考，不含滑点与流动性。
  • 分析弹窗（六模块深研卡）：点「分析」按参考研报形式给出最新业绩（报告期营收/归母/扣非同比、毛利率、ROE）、核心逻辑（按《深度研报分析流程》第 4 步结构化：驱动因素定性（涨价/订单/政策/技术突破/并购/景气/业绩）→ 多方依据（研报观点 + 盈利质量 + 资金验证 + 机构覆盖 + 题材催化）→ 可持续性校验（扣非口径、趋势动能、覆盖度）→ 空方/证伪点（目标价对撞、资金背离、风险项））、技术面与资金面（5/10/20 日涨跌、MA20 站位、距 60 日高、量能、RSI/KDJ、主力多周期净流入）、估值与机构预期（PE/PB、评级分布、一致目标价区间与隐含空间、EPS 盈利预测）、风险（商誉/负债/解禁/估值透支/背离/资金撤离）、操作建议（买点+止损+目标+仓位三要素，含交叉验证裁决）——六模块全部由云端 deep-factors.js 全网因子归纳生成，不引用财联社看板的调研结论原文；仅「已实现表现（T+1~T+5）」与「相关新闻」两栏来自看板。
  • 精选标的卡片：列表上方按短期（1~2 周）/ 中期（1~3 个月）/ 长期（6 个月+）三栏各精选 3 只（点击卡片打开完整深研卡，股票名可跳腾讯自选股）。候选为当前筛选范围内的股票（按代码去重取最新存档日），命中规避一票否决的股票一律不入选；短期按可执行框架 + 当日主力资金排序，中期按趋势 + 资金/目标价空间/扣非增长排序，长期按估值 / ROE / 商誉 / 负债 / 机构覆盖度排序，各取综合分前 3。
  • 三周期结论与规避档：每只股票的短期 / 中期 / 长期都给出明确档位——可操作 → 谨慎可操作 → 观察 → 不适合操作 → 规避。规避为一票否决：命中减持/立案/问询/处罚、看板「回避」桶、商誉占净资产 ≥30%、亏损 + 纯价格强势、PE>150 泡沫区、90 日内解禁 ≥5%、风险标签 ≥3 个任一项时，三周期直接定性「规避」，不再看分数，依据中逐条列出规避信号。
  • 表格标签：股票名旁「分析」后的 短 / 中 / 长 小标签与弹窗结论同口径——实心蓝 = 可操作、实色描边 = 谨慎可操作、虚线灰 = 观察 / 不适合操作、红色 = 规避。点标签或按钮均可打开完整分析。
