排序模型说明（v2 · 依据 2026-10-13 严格回测修订）

目标：在"上涨概率尽量高"与"上涨幅度尽量大"之间取得平衡，因此不单独按概率排序，而是按 期望收益 E[R] = P(上涨) × 上行空间 − (1−P) × 下行风险 降序排列。
  • P(上涨)：以偏弱市场为基准 47%，叠加信号调整，截断于 [12%, 88%]。
  • v2 新增 · 收盘封板 +0.06：回测（230 事件）显示 day0 收盘封死涨停的股票 T+1 均值 +2.78%、胜率 70%，显著高于其余事件（−1.34%，t≈3.2）——样本内唯一显著正向信号（连板溢价）。
  • v2 移除 · 追高惩罚（原涨停 −0.04 / 涨幅≥9.5% −0.03）：回测证明与真实驱动信号方向相反，v1 可回测部分综合分 IC = −0.20（显著为负），属于反向选择。
  • v2 移除 · 栏目权重加成：回测 IC ≈ −0.02，无预测力；栏目信息仅作展示参考。
  • 保留 · 未验证组件：技术趋势、偏多/偏空倾向、均线结构、博弈档位、潜力模型分、量能——这些因子依赖的技术/研究数据被看板刷新至最新时点，无法严格回测，保留但置信度打折。
  • 上行空间：现价至阻力位（看板关键位），缺失时按潜力分映射，上限 30%；下行风险：现价至止损位，缺失时用支撑位或默认 5%，上限 15%。
  • 硬风险置底：股东动向含立案/处罚/问询的股票强制排到最后，概率压至 ≤30%。
  • 执行纪律（封板股）：封板溢价依赖次日能以合理价格买入——仅当次日集合竞价涨幅 < 5% 时按模型执行；一字板或大幅高开放弃追入。
v1 → v2 排序变化：30 只封板股平均上移约 60 位（远程股份 +114、果麦文化 +93、欢瑞世纪 +72），Top20 成员保持稳定但内部顺序按回测证据重排。
本报告为数据驱动的量化排序演示，模型 v2 的修订依据 2026-10-08~12 单一周、单一行情（题材连板市）的样本内回测，尚未经样本外验证，不构成投资建议。快照为单一时点数据，概率与价位会随行情失效；封板股次日一字板可能无法买入，实际可得收益低于模型名义值。
