口径与方法

这份清单和看板原榜单的区别：看板按「动能分」 （RSI(14)×30% + KDJ(9,3,3)×30% + MACD(12,26,9)×40%）排序，衡量的是指标强弱； 本清单按可交易性重排——新闻催化强度 × 技术可否入场 × 位置风险，并给每条落到具体价位与作废条件。

分桶规则（互斥）

  1. 可执行：有明确低吸位与止损位 · 非涨停且当日涨幅 < 9.5% · 站上 20 日均线 · 博弈档位为「适合」或「可关注」
  2. 观察：当日涨停（收盘价买不到）／ 尚未站上 20 日线 ／ 关键位缺失
  3. 回避：技术面偏空，或 ≥2 个基本面风险标签，或近半年有减持/监管公告
  4. 复盘池：按看板「三个月潜力模型」分排序的长期跟踪池，非当日买入信号

可执行分 = 新闻催化（0–30：栏目权重×3 + 条数 + 博弈档位） + 技术结构（0–30：均线排列 / 趋势）+ 潜力模型（0–15）− 风险惩罚。 风险惩罚：涨停 −25、接近涨停 −8、量能暴增 −3、每个风险标签 −3、减持/监管 −5。

盈亏比 = (现价×1.08 − 低吸位) ÷ (低吸位 − 止损位)。 止损位离低吸位不足 1.5% 时视为不可用——那只是数据噪声，不是风控空间，此类标的会被主动剔除并列出。

重要边界（务必阅读）

  1. 这不是投资建议。所有价位来自几何推导（低吸位 = MA5，止损位 = 技术面「失效位」， 目标 = 现价×1.08 / ×1.15），是位置参考而非预测。
  2. 滑点与流动性未计入。清单未过滤成交额、涨跌停是否封板、次日是否停牌。
  3. 无同期基准。看板自身标注「基准对照：未计算」，因此本清单排序不能解释为 相对全市场的超额收益。
  4. 数据存在降级继承。看板每轮会继承上一版缓存，新闻可能是几分钟前的， 而技术面/调研结论可能来自 8–24 小时前的缓存，同一页面内不同字段新鲜度并不一致。
  5. 不复权价格。技术面基于不复权日线，精确价位存在约 1%（近一年）到 3%（250 日线）的偏差。
  6. 样本量提醒。部分栏目（如「机构调研」「掘金行业龙头」）在快照中可能仅 1 条记录， 统计表现不具参考意义，本清单已通过栏目权重下调此类来源。
